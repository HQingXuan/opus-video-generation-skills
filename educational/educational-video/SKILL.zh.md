# 科普视频

把一个问题讲清楚：目的 → 机制 → 具体例子 → 适用边界 → 结论。在用户当前项目中工作，优先复用合适的现有渲染器。本 skill 提供工作流，不内置渲染器或托管服务。适用于在编程环境中运行的 Opus，不选择或要求特定模型版本。

这是 [SKILL.md](SKILL.md) 的中文版本，共用一个 `educational-video` 命令。阅读中文说明本身不会改变视频语言；按下面规则选择。

## 解析请求

1. **语言。** 新视频默认英文，即使用户用中文提问。用户明确要求的输出语言优先。`--lang zh`、独立的 `中文` 选择词，或“视频用中文”表示中文；`--lang en` 或 `English` 表示英文。引号内的标题包含“中文”不算选择词。修改现有视频时沿用项目保存的语言，除非用户明确切换。当前请求的语言要求相互冲突时，先问一个聚焦的问题。上述写法由模型理解，不是可执行的命令行参数。
2. **模式。** “写 prompt”选择 `prompt-only`；“sample/preview/样片”选择 `preview`；延长已有视频选择 `extend`；其他制作请求选择 `full`。明确要求优先。如果要求先样片后成片，按顺序完成，只有用户要求先审核才暂停。“只做样片”则交付样片后结束。
3. **上下文。** 读取可用的来源、参考素材与项目指令。有现有样式时沿用；提到的旧视频不可用时说明情况，利用已知偏好，只有确实影响结果才请求素材。不能声称看过缺失的内容。
4. 只读取所选语言的工作流：[English](references/workflow.en.md) 或 [中文](references/workflow.zh.md)。
5. AWS 视频额外读取所选语言的 [English case library](references/aws-cases.en.md) 或 [中文案例库](references/aws-cases.zh.md)。它们是可调整的示例，制作前核对最新官方资料。其他题材不用加载 AWS 案例。

## 默认值与范围

用户要求和已有项目约定优先。否则使用：

- 成片 120 秒。样片为计划中的 30 秒视频先渲染 10 秒。扩展模式按用户要求的总时长，未指定则以总计 120 秒为假设并说明。
- 1920×1080、16:9、30 fps；米白背景、深色文字、橙色强调；简洁有标签的图形、克制动效、充足留白。这些是可修改的系列默认值。
- 简短可读字幕，不加旁白。使用有权使用或生成的音频；音频不可用时提供静音样片并说明。不能默默接入付费服务。
- 一个受众、一个中心问题、一个可追踪的例子；先解释术语，再使用术语。标签、字幕、用户要求的旁白和面向人的交付说明使用所选语言；保留 API 名称、来源标题、代码标识符和用户要求的双语术语。
- 科普模拟无需真实云凭证或基础设施。有工具时本地渲染；不要把部署资源、对外发消息或发布视频作为制作的附带动作。

## 完成标准

- **Prompt-only：** 交付可直接复制的完整 prompt，包含语言、时长、受众、视觉规则、定时分镜、已核实事实与边界、渲染器备选方案、验收检查。把相关指令直接写入 prompt，接收方无需安装本 skill。未要求时不安装或渲染。
- **Preview：** 交付约定样片、完整视频提纲、可编辑源码、抽样帧、如实的 QA 记录。10 秒样片不能称为两分钟成片。
- **Full / extend：** 交付成片、可编辑工程、共享时间线、分镜、事实来源、素材来源、复现命令与 QA 报告；尽量沿用项目文件名和约定。
- 工具阻碍渲染时，完成能做的分镜与可运行工程，明确缺少的能力和未执行的检查，并标记为未渲染。不能把缺失的产物说成已成功交付。

持续完成用户所要求的交付物。只有用户明确要求审核，或缺少必要信息时才设置暂停点。
